# Como usar o pacote CondoOS v1.0

Este pacote contém um **plano diretor em Word** e **prompts individuais** para coordenar a IA de desenvolvimento. O documento mestre de especificação acompanha o ZIP como fonte de referência.

## Ordem de trabalho

1. Disponibilize à IA o **Plano Diretor (.docx)**, a **Especificação Mestra (.md)**, o **Design System existente** e o repositório real.
2. Execute o **01_PLANEJADOR_MESTRE.md**; em seguida aprofunde com **02_AUDITORIA_CODIGO.md**.
3. Execute **03_BACKLOG_DEPENDENCIAS.md**, **04_ARQUITETURA_DADOS_SEGURANCA.md** e **05_UX_FLUXOS.md**.
4. Construa em incrementos com **06_CORE_ADVISOR.md** e **07_OPTIMIZE.md**.
5. Só avance com **08_OPERATE_AUTOMACOES.md** após gates de autorização e auditoria.
6. Conduza validação com **09_PILOTOS_MEDICAO.md** e gate com **10_QA_GATE_RELEASE.md**.
7. Em cada ciclo, reutilize **11_EXECUTAR_PROXIMA_FATIA.md**.

**Regra central:** a IA deve inspecionar o código real, preservar o Design System, executar uma fatia por vez, testar e registrar evidências. Proposta de IA não é autorização para pagamentos, mensagens, contratações ou ações em produção.

## Observação

O Design System e o repositório não estão neste pacote porque não estavam anexados a esta solicitação. As instruções exigem que sejam lidos pela IA na hora de executar.
