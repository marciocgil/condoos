Documento: comprovante de pagamento (boleto pago, transferência, PIX ou TED) emitido pelo banco do condomínio.

Campos:
- data_pagamento: data em que o pagamento foi efetuado (não a data de vencimento).
- valor: valor efetivamente pago.
- nome_beneficiario / documento_beneficiario: quem RECEBEU o dinheiro (o "beneficiário final", "favorecido" ou "recebedor"), com o CPF ou CNPJ dele. Nunca use o banco que processou o pagamento nem a instituição emissora do boleto: se o comprovante mostrar "beneficiário" (o banco) e "beneficiário final" (a empresa), use o beneficiário final.
- banco_pagador: o banco de onde saiu o dinheiro.
- autenticacao: o código de autenticação ou o identificador da transação, como está escrito.
- linha_digitavel: a linha digitável ou o código de barras pago, só os dígitos, se constar.
